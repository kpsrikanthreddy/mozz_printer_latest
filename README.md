# Mozz Print Agent

Windows desktop print agent for Starters4U restaurant KOT and bill printing. It receives authenticated branch-scoped print jobs from the Starters4U backend and submits them silently to printers already installed in Windows.

## Requirements

- Windows 10 or Windows 11 for physical printer use
- A printer installed through Windows with a working driver
- Node.js 20 for development only; restaurant computers do not need Node.js after installing the packaged app
- A six-digit pairing code generated by an authorized restaurant user

## Local development

```bash
npm ci
npm run lint
npm test
npm run build
```

The development-only token fallback is disabled by default. Automated tests use isolated test storage. Never enable the fallback in a packaged production build.

## Windows installer

Push this folder as the root of its own `mozz_printer` GitHub repository. The workflow in `.github/workflows/build-windows.yml` runs the checks and produces the NSIS installer and portable executable as downloadable workflow artifacts.

To build directly on Windows:

```bash
npm ci
npm run build:win
```

Artifacts are written to `release/`. Generated executables, runtime databases, preferences, `node_modules/`, `dist/`, and `release/` must not be committed.

## Canon G3010 A4 test

The Canon G3010 is useful for validating printer discovery and the Windows-driver printing path, but it cannot validate thermal roll sizing, speed, auto-cutting, or ESC/POS behavior.

1. Install the Canon G3010 series Windows driver.
2. In Windows, open **Settings > Bluetooth & devices > Printers & scanners > Canon G3010 series**.
3. Print a Windows test page successfully.
4. Install and open Mozz Print Agent.
5. Pair it with the six-digit code from the Starters4U admin portal.
6. Open **Printers**, refresh the list, and select **Canon G3010 series**.
7. Select **A4 Test Only (Canon G3010)**.
8. Click **Save Config** before testing.
9. Run **Test Print** (mock mode is automatically bypassed for real hardware tests).
10. Place one test order on starters4u.in and confirm exactly one KOT and one bill are submitted.

Before restaurant rollout, repeat acceptance testing with a real 80mm thermal printer. See `PRINTER_ACCEPTANCE_CHECKLIST.md`.

## Security notes

- Production device tokens are encrypted using Electron `safeStorage`/Windows DPAPI.
- The agent refuses to persist a token in a packaged build if secure OS storage is unavailable.
- Database credentials, JWT secrets, QR signing secrets, Razorpay secrets, and Supabase service-role keys never belong in this repository.
- The application will not print a cloud job unless the backend confirms its atomic claim.
